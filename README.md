# Duuk Hub releases

This repository holds only the release files of the Duuk Hub apps (Duuk Hub, DuukCAD, JMPy):

- `manifest.json`: the newest version of each app, read by Duuk Hub to install and update them;
- the GitHub Releases: one zip per app version.

It contains no source code.

Each app is licensed under the MIT and/or Apache-2.0 licenses, as stated in the license files inside its zip
(for example `LICENSE`, `LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE`, `THIRD-PARTY-LICENSES.txt`).
